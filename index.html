ESP32 ควบคุมรอบมอเตอร์

กระบวนการทำงานของ motor_rpm_control_v2.ino ตั้งแต่อ่านเซนเซอร์ คุมรอบแบบ PI ไปจนถึงส่งข้อมูลขึ้น MQTT และ Firebase

100 msรอบการคุมมอเตอร์
20 kHzความถี่ PWM
4เซนเซอร์
2 แกนloop + Firebase task

1. ภาพรวมระบบ

เซนเซอร์ส่งค่าเข้า ESP32 → สั่งมอเตอร์ → ส่งข้อมูลออก และรับคำสั่งกลับทาง MQTT

2. ขั้นตอนตอนเปิดเครื่อง (setup)

มอเตอร์ยังไม่หมุนจนกว่าทุกอย่างพร้อม เพื่อให้ calibrate กระแสได้ถูกต้อง

3. วงจรหลัก: งานแต่ละอย่างทำงานตามเวลา

แกนเวลา 1 วินาที (จุด 1 จุด = 1 ครั้งที่ทำงาน) loop เช็กด้วย millis() ไม่ใช้ delay

ทุกรอบของ loop ยังทำ: เช็ก WiFi (ลองใหม่ทุก 5 วินาที) · อ่านคำสั่ง Serial · เชื่อม MQTT ใหม่ทุก 2 วินาทีถ้าหลุด · mqtt.loop()

4. การวัดรอบ (RPM)

วัดจากเวลาระหว่าง pulse แต่ละครั้ง จึงละเอียดแม้รอบต่ำ

5. ตัวควบคุมรอบแบบวงปิด

Feedforward ให้ค่าตั้งต้น แล้ว PI แก้ส่วนที่คลาดเคลื่อน รอบจริงถูกป้อนกลับมาเทียบทุก 100 ms

6. คำสั่งที่รับได้

ส่งได้ทาง MQTT (motor/cmd) และ Serial Monitor (line ending = Newline)

rpm:1500ตั้งรอบเป้าหมาย (พิมพ์ 1500 เฉย ๆ ก็ได้) · โหมดอัตโนมัติ
stopหยุดมอเตอร์ ล้าง integral
pwm:150โหมดแมนนวล สั่ง PWM 0–255 ตรง ๆ
kp:0.05ปรับ Kp ขณะรัน
ki:0.10ปรับ Ki ขณะรัน (ล้าง integral)
max:3000ปรับรอบสูงสุดโดยประมาณ
minpwm:60ปรับ PWM ต่ำสุดที่มอเตอร์ยังหมุน

7. แบ่งงานสองแกนของ ESP32

Firebase ตอบช้า จึงแยกไปทำบน core 0 เพื่อไม่ให้การคุมมอเตอร์ช้าลง

8. เกณฑ์แจ้งเตือน

ตรวจทุก 1 วินาทีและพิมพ์ทาง Serial เท่านั้น โปรแกรมไม่ได้หยุดมอเตอร์อัตโนมัติ
